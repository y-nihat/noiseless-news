## What happened

On 11 August, Anthropic said it would start embedding a statistical
watermark in text generated by Claude models, tying the move to the EU AI
Act's transparency Code of Practice, which took effect 2 August. On 14
August it published a follow-up post explaining the mechanism: where a
sentence has multiple word choices of roughly equal meaning, Claude's token
selection is biased using a secret key plus the preceding tokens, leaving a
statistical pattern detectable without altering the text's meaning.
Anthropic says the approach is in the same family as Google DeepMind's
SynthID-Text.

By Anthropic's own account the signal has real limits: it isn't applied to
code at all, and it's faint in text tightly constrained by facts, which
leaves little room for word-choice variation. It survives light editing but
is lost under heavy rewriting, paraphrasing, or translation. Anthropic says
it will "soon" offer a watermark detection API for third parties but has not
released one yet and is still working out the implementation. The company
states plainly that the watermark does not prove authorship: it can only
indicate Claude was "likely involved," can't distinguish text Claude wrote
from text it heavily edited, and can't identify text from other companies'
AI systems.

## Why it matters

As regulators require AI-content transparency and institutions scrutinize
AI use in writing, watermarking is being positioned as basic infrastructure
-- but Anthropic's own description makes clear it's a faint, gameable signal
rather than proof. Security researchers have separately noted that once a
public detection API exists, it can serve as a feedback oracle for
iteratively stripping the watermark, a risk Anthropic has not yet addressed
publicly.
